### 🚀 Featured Projects

#### 🧠 [AIDEN](https://github.com/fatma-ouertani/devops-ai-agent) — Multi-Agent AI DevOps Automation
A multi-agent system that takes a natural-language request and ships it — analyzing the repo, generating pipelines, deploying to Kubernetes, and monitoring the result. Built as my final-year engineering capstone.
- **8 specialized agents** orchestrated end-to-end, with an **Intent Compiler** (12 signals → 4 scores → 5 deployment strategies)
- **Human-in-the-loop by design**: 5 mandatory checkpoints before any production action, with a full explainable audit trail
- **Episodic memory** (ChromaDB + PostgreSQL) so the system learns from past deployments
- Deployed real Django, FastAPI, and Wagtail CMS apps end-to-end onto a K3s cluster on Azure
- **Stack:** `FastAPI` `React` `TypeScript` `Kubernetes (K3s)` `Azure` `Ollama` `ChromaDB` `PostgreSQL`

#### 🛰️ [JiraGuard](https://github.com/fatma-ouertani/jiraguard) — Flight Recorder for AI Agents
A transparent proxy that sits between AI agents and the Atlassian ecosystem, recording every action for deterministic replay, "What-If" scenario injection, and AI-powered root cause analysis. Built at the **AINS Hackathon 2026**.
- Real integration with **Atlassian Jira Cloud**
- Live trace viewer over WebSockets, root-cause analysis powered by an LLM
- **Stack:** `FastAPI` `SQLite` `Groq LLM` `WebSockets`

#### 🌍 EarthBeats (Terra Pulse) — GeoAI for Ecosystem Restoration
A GeoAI serious game turning real satellite data into a restoration-planning tool for Tunisia and the MENA region. Built for **MSE Hack 1.0** and presented at the **Prix Orange de l'Entrepreneur Social**.
- Ingests real data from **NASA FIRMS**, **Google Earth Engine**, and **Copernicus Sentinel-2**
- GPT-4o agents turn satellite signals into playable restoration scenarios
- **Stack:** `React` `FastAPI` `GPT-4o` `Google Earth Engine`
